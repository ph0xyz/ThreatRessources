# Contributing

Thanks for helping to extend the ThreatRessources list.

## Suggest a source

Check the [README](README.md) for duplicates first. You can open an issue with the this template:

```md
### URL
Direct link to the advisory page, feed, newsletter, or tool:

### Type of source
Manual Reader / RSS / Newsletter / IOC Feed / Other:

### Description
What does it provide?

### Why is it useful?
How does it help the community?

### Language
If it is not in English, why is it relevant to the wider cybersecurity community?
```

English-language sources are preferred. Feeds should use standard machine-readable formats, such as RSS, CSAF or Atom. Link directly to the feed when possible.

## Update the list

Pull requests are welcome for new sources, fixes, and removals. Please:

- Use reliable, preferably official sources.
- Check that links work and point to the right page or feed.
- Add entries to the most relevant section and follow its style.
- Keep descriptions short and factual.
- Remove tracking links. Never include passwords, tokens, or private information.

## Before you submit

Check your links, section placement, and Markdown preview.

Thanks for contributing!
